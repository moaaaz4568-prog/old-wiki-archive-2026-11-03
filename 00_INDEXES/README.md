# 📑 فهرس التقارير والمستندات المصدرية — 00_INDEXES

## 1. نبذة عامة
يحتوي هذا المجلد على جميع وثائق الحصر والمسح الشامل وتحليل الفجوات وخطط التنفيذ التي أُنتجت خلال مرحلة التدقيق والتحليل الشامل لنظام Nexus ومشاريع الويكي المرتبطة به قبل البدء بعملية الأرشفة الموحدة.

---

## 2. قائمة المستندات والتقارير المرفقة

| المستند | الوصف والدور التقني |
| :--- | :--- |
| `preflight_df.txt` | تسجيل فحص المساحة التشغيلية المبدئية لوحدة التخزين `/mnt/sdcard` قبل بدء النسخ |
| `master_inventory.json` | الجرد الآلي المفصل والشامل لجميع المكونات والملفات والأحجام بصيغة JSON الموحدة |
| `WIKI_ARCHIVE_EXECUTION_PLAN.md` | خطة الأرشفة الشاملة المعتمدة وتوزيع الميزانيات التخزينية وسلالم الأمان |
| `SDCARD_WIKI_INDEX_REPORT.md` | تقرير حصر وفهرسة كل ملفات ومجلدات الويكي على مسار `/sdcard` |
| `WIKI_INDEX_REPORT.md` | تقرير حصر وفهرسة وثائق الويكي في مسار الجذر `/root/r` |
| `WIKI_CONVERSATION_SCAN_REPORT.md` | تقرير استكشاف وفحص محادثات Claude Code التاريخية المرتبطة بالويكي |
| `OPencode_DB_WIKI_SCAN_REPORT.md` | تقرير فحص واستخراج بيانات جلسات OpenCode Interpreter من قواعد SQLite |
| `AGY_WIKI_CONVERSATIONS_SCAN_REPORT.md` | تقرير فحص ومسح سجلات جلسات Antigravity CLI |
| `OMNIRUSH_WIKI_CONVERSATIONS_SCAN_REPORT.md` | تقرير استخراج وفحص سجلات محادثات OmniRush من قواعد بياناته |
| `EXPLORATION_REVIEW_REPORT.md` | المراجعة النقدية وتقييم تقارير الاستكشاف الستة لتحديد الفجوات المعمارية |
| `GAP_CLOSURE_REPORT.md` | التقرير التنفيذي لإغلاق الفجوات الاستكشافية السبع وتأكيد الروابط |
| `GAP_SIZES_REPORT.md` | القياس الكمي والحجمي الدقيق للفجوات ومصادر التخزين لتثبيت ميزانية النقل |

---

## 3. منهجية الحفظ والسلامة
- جميع الملفات منسوخة بأمر الإضافة الآمنة (`cp`) دون أي حذف (`Zero Deletion`).
- تم الاحتفاظ بالحالة الأصلية للتقارير للرجوع إليها كمرجع موثق لمسارات ومصادر ومخرجات الأرشفة.
