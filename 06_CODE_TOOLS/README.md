# ⚙️ حزمة أدوات الكود والكومبايلر — `06_CODE_TOOLS`

## 1. نظرة عامة والهدف
يحتوي هذا المجلد على كود الأدوات والمكونات البرمجية الأساسية لإدارة وبناء وصيانة الويكي للنماذج اللغوية (LLM Wiki)، منقولة من `/root/r/NEXUS_REFERENCES/`.  
الحجم الفعلي الإجمالي: **16.4MB** (ضمن ميزانية 26MB المحددة في خطة الأرشفة).

المجلد يضم مكونين رئيسيين:
1. `llm-wiki-compiler/` (11MB): المترجم ومنظومة التجميع والبروتوكولات ومهارات Claude/AGY المدمجة.
2. `llm-wiki-plugin/` (5.4MB): الإضافة الموسعة ومكتبة الأوامر الداعمة لإدارة دورة حياة الويكي.

---

## 2. المقارنة والفروق الجوهرية (Compiler vs Plugin)

| الخاصية | `llm-wiki-compiler` | `llm-wiki-plugin` |
|---|---|---|
| **الدور الأساسي** | ترجمة وبناء الرسوم البيانية المعرفية، أتمتة بروتوكول التجميع (`COMPILE_PROTOCOL.md`) وتوليد الفهارس | إضافة أدوات طرفية لأوامر الصيانة، والتحسين التطوري (Evolve)، واستخلاص الإحصاءات |
| **طبيعة المكونات** | نصوص تنفيذية Bash/PowerShell، مهارات وقوالب (Templates & Hooks)، أدوات التمثيل البصري | مكتبة TypeScript/Node وأوامر Markdown متخصصة ونماذج تقييم (Eval) وأبحاث |
| **المستهدف** | محرك البناء والتكامل المستمر مع بيئات الذكاء الاصطناعي | واجهة الأوامر التفاعلية للمطور والعميل الذكي |

---

## 3. العناصر المستثناة وأسباب الاستثناء (Exclusion Ledger)
- **`__pycache__` و `*.pyc`:** تم استثناؤها بالكامل من كلا المجلدين لمنع تضخم الكاش المؤقت.
- **`.git` في `llm-wiki-plugin`:** تم استثناء سجلات git لتوفير 3.7MB من بيانات النسخ السابقة.
- **`node_modules`:** تم استثناؤها لعدم حشو الأرشيف بالحزم التابعة التي يُعاد تثبيتها عبر `pnpm install` عند الحاجة.

---

## 4. أمثلة أوامر `wiki-*` المدعومة واستخداماتها

### أوامر `llm-wiki-compiler`:
- `wiki-init.md`: تهيئة بيئة ويكي جديدة متوافقة مع مواصفات Nexus.
- `wiki-compile.md`: تجميع كافة الملفات والمستندات الذرية وتوليد شبكة الروابط.
- `wiki-lint.md`: التحقق الصارم من سلامة الروابط الخلفية والوسوم والكسر الدلالي.
- `wiki-visualize.md`: توليد الرسوم التوضيحية وشبكة العلاقات ثلاثية الأبعاد.
- `wiki-capture.md`: التقاط مصادر جديدة وحقنها في الـ Intake.
- `wiki-migrate.md`: ترحيل وترقية هياكل الويكي السابقة للإصدار الحديث.

### أوامر `llm-wiki-plugin`:
- `/wiki:init`: تهيئة سريعة داخل المحادثة للأنظمة المعتمدة.
- `/wiki:ingest`: إدخال مصادر جديدة ومعالجتها تلقائياً.
- `/wiki:query`: استعلام دلالي فوري وسحب السياق للمطابقة.
- `/wiki:evolve`: تطوير وتحديث صفحات الويكي مع تراكم الأدلة الجديدة.
- `/wiki:graph`: توليد مخطط العلاقات والمفاهيم.
- `/wiki:lint`: الفحص الإحصائي لسلامة النسيج المعرفي.
- `/wiki:stats`: تقرير شامل بحجم الويكي وعدد المفاهيم والروابط المتقاطعة.
