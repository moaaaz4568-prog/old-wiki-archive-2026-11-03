## 3. سجل الملفات الثقيلة المستثناة (`BIG_FILE_POINTERS.csv`)
تم توثيق **1,822 ملفاً مستثنى** بالتفصيل في الملف المرفق [`BIG_FILE_POINTERS.csv`](BIG_FILE_POINTERS.csv)، ويتضمن لكل ملف:
1. المسار المطلق في المصدر الأصلي (`/sdcard/NEXUS_LLM_WIKI/...`).
2. البصمة الرقمية الدقيقة (`sha256`).
3. الحجم الدقيق بالبايت.
4. سبب الاستثناء (`raw_unprocessed_source_excluded` أو `heavy_collection_ledger_excluded`).

---

## 4. خطوات استعادة واستنساخ البيانات المستثناة (Restoration Recipe)
عند توفر سعة إضافية والحاجة إلى استرجاع أي جزء من الملفات المستثناة:
1. **استعادة المصادر الخام (`raw/`):**
   ```bash
   cp -r /sdcard/NEXUS_LLM_WIKI/raw ./
   ```
2. **استعادة سجل الأدلة (`full_evidence_ledger`):**
   ```bash
   mkdir -p ./collections/sales
   cp /sdcard/NEXUS_LLM_WIKI/collections/sales/full_evidence_ledger.jsonl ./collections/sales/
   ```
3. **أو إعادة توليد الأدلة برمجياً:**
   ```bash
   python3 ./tools/build_sales_full_evidence_ledger.py
   ```
