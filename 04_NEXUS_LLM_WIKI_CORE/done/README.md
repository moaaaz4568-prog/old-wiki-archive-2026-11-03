# تنظيم المصادر في done — عقد 2026-10-10

[فهرس المجالات](INDEX.md) — [الكتالوج وسياسة النسخ](../config/domain_catalog.json)
— [حالات الاكتمال والبوابات](../config/processing_order.json).

المسار الملموس **`done/<domain>/<subdomain>/`** يحتوي نسخة المصدر نفسها، مستقلة
ومتطابقة بالبايت، ومعها route metadata. ليس مجرد رابط إلى raw وليس مسار
`source_refs/`. الأصل immutable لا يُنقل أو يُحذف أو يُعاد تسميته.

## نسخ آمن وهوية واحدة

نسخة regular file مستقلة لا symlink ولا hardlink؛ تحقق من تطابق البايتات
وSHA-256 والحجم بين الأصل والنسخة وسجل فحص الاستقلال. لا تغيير ترميز ولا
overwrite. تحتفظ metadata بـsource_id ومساري الأصل والنسخة وبصمتيهما والمجال
الأساسي والفرعي وسبب التوجيه ومواضع القراءة ومداها وحالات منفصلة وsnapshot.
المصدر متعدد الموضوعات له نسخة رئيسية واحدة فقط وإحالات ثانوية لا تُحسب أدلة جديدة.

## وجود الملف في done ليس اكتمال المعرفة

| الحالة | معناها |
|---|---|
| route_done / R | اكتملت القراءة اللازمة للتصنيف والتوجيه والتحقق من النسخة؛ مسموح لمجال pending |
| source_done | اكتمل استخراج مساهمات المصدر ومراجعتها؛ لا يحتاج Master |
| subdomain_extraction_done | اكتمل استخراج ومراجعة مصادر snapshot لهذا المجلد؛ لا يسمح وحده بـMaster صغير |
| domain_terms_complete / T | كل مصادر المجال وكل subfolders في snapshot شامل مغلق لها مصطلحات مراجعة؛ ليس عينة |
| C | ادعاءات ذات اقتباس وموضع وسياق ونوع دليل ومراجعة، وتُجمع مرشحاتها مع Terms |
| K | Concepts مبنية على Claims مراجعة قابلة للتتبع، مع الحدود والخلافات |
| M | Masters مراجعة لا يبدأ أي منها قبل T وC/K اللازمة، بما فيها الصغيرة |
| QA / domain_done | مراجعة مستقلة وفهارس وروابط واسترجاع وسجل إغلاق على snapshot حديث؛ يفتح المجال التالي فقط |

عقد المواءمة هو الذي يفصل هذه الحالات، لا اسم المجلد. sales ما زال in_progress؛
البقية pending معرفيًا مع السماح بـglobal_intake_routing. لا يتطلب إعداد الويكي
بيعًا فعليًا أو عرضًا مثبتًا؛ الترتيب لتنظيم المعرفة فقط.

## ما لا يُكرر هنا

- `source_refs/` وجميع مجلداته القديمة **legacy indexes** تحيل إلى المسارات
  المباشرة. تُحفظ ولا تُحذف، ولا تحتوي نسخ مصادر أو مصدرًا canonical ثانيًا.
- `terms/claims/concepts/masters/reports/` تحت كل مجال فهارس للطبقات الأصلية
  حسب [خريطة config](../config/INDEX.md)، لا معرفة مكررة ولا تقرير QA منسوخ.
- pending ليس quarantine؛ الغموض uncertain/cross_domain_review. quarantine
  فقط لملف missing/corrupt/unreadable مع سبب موثق. اختلاف مدعوم يُحفظ ولا يُحذف.

## snapshots والمصادر المستقبلية

المقام هو كل المرشحين ضمن حدود المجال وجميع مجلداته، مع استبعادات معللة
ومرشحين غير محسومين ظاهرين. وصول مصدر جديد ذي صلة يجعل التغطية stale ويضيف
delta، ولا يمد إغلاق اللقطة القديمة للمخزون الجديد. تُراجع delta وتُجدول تحت
قفل المجال الواحد قبل أي انتقال جديد أو ادعاء تغطية حديثة.

هذه المراجعة أنشأت فهارس مباشرة فقط ولم تنفذ قراءة raw دلالية أو نسخًا أو
route_done أو source_done. الـ21 اسمًا السابق محفوظة، وأضيف negotiation
provisional استجابة لذكر المستخدم التفاوض، فأصبحت المقترحات 22؛ لا نجاح بوابات مفترض.
