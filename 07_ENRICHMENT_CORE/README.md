## 4. ما استُثني من مجلد `nexus_enrichment` الأصلي (209MB) ولماذا؟
استُثني ما يقارب **207MB** من الملفات المؤقتة والوسيطة للأسباب التالية:
- **`state/runs/`:** تشغيلات وسيطة وبيانات مرحلية مؤقتة.
- **`media_shard*` و `kaggle/standalone_*`:** مخلفات استخراج وسائط ومخرجات أولية خام.
- **`raw/`, `processed/`, `drafts/`:** بيانات معالجة أولية قابلة لإعادة التوليد عبر خط الأنابيب البرمجي.
- **`.pytest_cache`, `.opencode`:** كاش تشغيلي وملفات تهيئة محلية لا تمثل معرفة دائمة.
