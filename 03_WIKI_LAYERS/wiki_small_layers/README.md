# 🧠 Nexus Wiki V3 - عقل ثانٍ للموديل

**الرؤية:** ويكي معرفية تعمل كعقل ثانٍ للـ LLM — معرفة حقيقية، مش تخمين.

---

## 📂 البنية

```
wiki/
├── raw/              # المصادر الخام
│   ├── new/         # ملفات جديدة للمعالجة
│   └── done/        # تمت معالجتها
│
├── wiki/            # الويكي الفعلية
│   ├── concepts/    # المفاهيم المستخرجة (بالطريقة الصحيحة)
│   ├── masters/     # الماسترز (Core + Specialized)
│   └── systems/     # ملفات النظام وتوثيق العمليات
```

---

## 🎯 المبادئ الأساسية

### 1. الجوهر قبل الشكل
```
❌ خطأ: أخذ المثال كقاعدة
✅ صح: استخراج الآلية من وراء المثال
```

### 2. كل عملية موثقة
كل خطوة في النظام لها ملف في `systems/` يشرح:
- **لماذا** (Why)
- **كيف** (How)
- **متى** (When)
- **الأخطاء الشائعة**

### 3. التعلم من الأخطاء
كل خطأ يُسجل في `systems/99_LESSONS_LEARNED.md`

---

## 🚀 البدء

اقرأ أولاً:
1. `/sdcard/NEW_WIKI_MASTER_PLAN.md` - الخطة الكاملة
2. `systems/00_WHY.md` - لماذا هذا النظام؟
3. `systems/01_EXTRACTION.md` - كيف نستخرج المعرفة؟
