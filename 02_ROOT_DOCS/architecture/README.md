# V3_SYS — نظام الأرقام الوحيد

## لماذا

أي رقم يُكتب يدوياً في وثيقة يصبح كذباً خلال أسبوع: الشجرة تتحرك، الملفات تُضاف
وتُحذف، والوثيقة القديمة لا أحد يحدّثها. المشكلة أن الأرقام كانت موزّعة على عشرات
وثائق، لكل منها نسختها. `count.py` هو **المصدر الوحيد**: لا تكتب رقماً، بل تقرأ
`COUNTS.json` أو تلصق `COUNTS.md`. رقم غير موجود في `COUNTS.md` = رقم مُختلق.

## المخرجات

| ملف | الحجم | الغرض |
|---|---:|---|
| `COUNTS.json` | 7,713 بايت | المصدر الآلي (226 مفتاحاً مسطّحاً) |
| `COUNTS.md` | 6,356 بايت | جداول ماركداون جاهزة للصق في أي وثيقة |
| `count.py` | 31,707 بايت | المولّد — stdlib فقط، بلا glob، بلا شبكة |

## الأوامر

```bash
# توليد/تحديث (يكتب JSON)
python3 /root/r/V3_SYS/count.py \
  --root /root/r/NB2 \
  --root /root/r/NEXUS_GITHUB_PACKAGE/WIKI/01_ACTIVE_WIKI \
  --out /root/r/V3_SYS/COUNTS.json

# جدول ماركداون
python3 /root/r/V3_SYS/count.py --out /root/r/V3_SYS/COUNTS.json --md /root/r/V3_SYS/COUNTS.md

# مقارنة بالمحفوظ — لا يكتب، ويطبع الفروقات فقط (exit 1 عند اختلاف)
python3 /root/r/V3_SYS/count.py --out /root/r/V3_SYS/COUNTS.json --check
```

المخرجات **بلا أختام زمنية** عمداً، فالمخرج مطابق بايت-ببايت عند كل تشغيل. زمن التنفيذ
≈ 4–7 دقيقة (القرص I/O-bound: مسح 47MB نص يستهلك وحده 225–311 ثانية).

## ما كشفه العدّ

1. **`terms_26k` لا يتبع قالب البطاقة إطلاقاً.** من 27,742 ملفاً: `## الآلية` = 0،
   `## حدود الفناء` = 0، `## الدليل` = 0، `## المصدرية` = 0، `## التوترات` = 0.
   البطاقات خارج `terms_26k` (1,841 ملفاً) تلتزم الخماسية بنسبة 99.57%. أيّ وثيقة
   تقول "27k مفهوم مكتمل" غير صحيحة: هي بطاقات مصطلحات بقالب مختلف.
2. **`99_misc` يبتلع 10,064 ملفاً = 36.28%** من `terms_26k` — أكبر من كل قطاع
   منظّم، فهو حاوية مهملة لا قطاع.
3. **`part_NN` حدّها 900 ملف** بالضبط في 21 موضعاً من 49 — أثر تقطيع دفعي، لا حدّ طبيعي.
4. **`TRASH` = 4,056 ملفاً** (10.93% من NB2) — حجم يعادل أكبر قطاع في `terms_26k`.
5. **`NB2/03_MASTERS` ليس مستودع الماسترز**: 10 ملفات في 5 قطاعات، بينما
   `v1/nexus_vault` فيه 39 `Master_*.md` حيّاً + 31 مؤرشفاً = 70.
6. **`wiki/` غير موجود** في الويبكي النشط: `concepts` = 4 و`keywords` = 3 على مستوى
   الجذر، و`sources`/`entities`/`tools` **غير موجودة إطلاقاً** (تُسجَّل `MISSING`).

## قاعدة الاستعمال

لا تعدّ يدوياً. شغّل `count.py`، الصق `COUNTS.md`، وإن اختلف reality استعمل `--check`.
