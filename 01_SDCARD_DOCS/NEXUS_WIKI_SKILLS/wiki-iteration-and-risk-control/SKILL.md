# دورة التخطيط والتنفيذ والمراجعة

## الدورة

`baseline → plan → bounded execution → validation → failure log → revised plan → regression test → checkpoint`.

## قواعد الوكلاء

- كل Agent له مهمة واحدة ومسار نتيجة معروف.
- لا يُحتسب الإنجاز برسالة؛ يلزم ملف نتيجة وفحصه.
- افصل Agents الاستخراج عن المراجعة والتحكيم.
- لا تسمح لوكيل بكتابة raw أو تعديل سجل لا يملكه.
- عند فشل التفويض، نفّذ المهمة محليًا وسجّل الفشل بدل إخفائه.

## مخاطر corpus الكبير

راقب: تكرار المصادر، اعتماد المصادر بعضها على بعض، تضخم الفهرس، انجراف المصطلحات، أرقام بلا سياق، آراء متعارضة، تغيّر الزمن، فقدان الروابط، overflow للسياق، وتراكم Masters غير مختبرة.

## checkpoint

سجّل الأعداد، الملفات، الاختبارات، الإخفاقات، القرارات، وما لم يُنجز. checkpoint ليس إعلان نجاح؛ هو نقطة استئناف قابلة للتحقق.
