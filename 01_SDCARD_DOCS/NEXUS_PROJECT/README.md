## 3) قاعدة التحديث — غير قابلة للتفاوض

1. **كل جلسة تُحدّث `worklog.md`.** سطر واحد لكل حدث على الأقل، بعمود `النتيجة`.
2. **`worklog.md` append-only.** لا تحذف سطراً · لا تعدّله · لا تعِد الترتيب. التصحيح = سطر تصحيح جديد يشير إلى رقم السطر القديم.
3. **أي رقم يُكتب في أي مكان من هذا المجلد يُنسب إلى أمره.** رقم بلا أمر shell = صفر قيمة.
4. **الأرقام تُنسخ من `V3_SYS/COUNTS.json`** عبر `count.py` — لا تُكتب يدوياً أبداً. انظر `memory.md §1`.
5. **هذا المجلد لا يُحذف ولا يُزاح.** لا `rm` · لا `rmdir` · لا `shred` · لا `dd`. التصحيح = سطر مضاف فوق القديم.
6. **صفر كتابة خارج هذا المجلد.** الـZIP الاحتياطي لا يُغني عن السجل النصي.
