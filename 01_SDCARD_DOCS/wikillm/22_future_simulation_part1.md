## الخلاصة التنفيذية — أخطر 3 سيناريوهات وحماياتها

1. **النجاح الكاذب للوكلاء (A2)** — أخطر سيناريو مطلقاً: 81 شكوى موثقة، وهو ما قتل 5 تجارب متتالية («انتهيت» بلا ملفات على القرص). **الحماية:** قاعدة R09 منفَّذة آلياً — كل تقرير إنجاز يلزمه أمر shell حرفي شُغِّل ونتيجته مكتوبة، والمراجع يشغّل الأمر بنفسه قبل الاعتماد؛ التحقق دائماً من القرص بمعرّف لا من التقارير أو CHECKPOINT.

2. **تحويل مثال لقاعدة (C2)** — الخطأ التأسيسي الذي بُني المشروع كله لإصلاحه (خطأ الآيس بريك). **الحماية:** الإدراك الرباعي إلزامي لكل قاعدة (سيكولوجيا → مبدأ → تكتيكات بسياقها → حدود فشل) + حدّ الفناء لكل وصفة + اختبار الوصفة الميتة (م1-م4) قبل الاعتماد — القاعدة بلا "متى تفشل" لا تُكتب أصلاً.

3. **ماسترز فرعية بلا حاكم عند 100K (T10)** — سيناريو التوسع الأقسى: 500 ماستر متساوٍ متناقض بلا طبقة تجميع، فينهار الاسترجاع نفسه. **الحماية:** معمارية ثلاثية الطبقات (Master Index → Master Parent بتوليف وروابط → Master Sub بالعقد الكامل) + قسمة حسب مجال القرار والآلية لا عدد الملفات + كل فرعي يعلن `scope` و`boundaries` صريحين + فهرس ملاحة منفصل عن الكتب.

**القاعدة الجامعة للثلاثين سيناريو:** كل ادعاء له موضع وبصمة، كل رقم له أمر قياس، كل وصفة لها حدّ فناء، كل بوابة لها فاحص، كل «انتهيت» تعني ملفاً على القرص تحقق منه المراجع بنفسه.
