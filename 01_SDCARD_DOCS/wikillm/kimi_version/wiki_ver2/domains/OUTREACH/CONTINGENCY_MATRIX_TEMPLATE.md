# CONTINGENCY MATRIX TEMPLATE

> **هذا القالب فارغ — ممنوع ملؤه بمحتوى معرفي في مرحلة بناء الأنظمة والهيكل والقوالب فقط.**
> يُملى محتوى Contingency Matrix لاحقاُ (مرحلة التنفيذ) عند وجود تعارض رأي حقيقي في مصادر القطاع.
> لا تكتب في هذا الملف غير التعليمات أدناه.

**ماذا يبنى هنا:** مصفوفة الآراء المتعارضة لكل موقف رئيسي في نطاق الفرع — لا جمع عشوائي.
الغرض: منع تحويل الـPLAYBOOK إلى دعاية ذات اتجاه واحد (الـAnti-Dead Formula).
القاعدة: **لا مصفوفة إلا إذا كان هناك توتر حقيقي** (≥2 رأي معقول متعارض).

## العمود الإجباري (كل صفة تُحدّد سطرًا)

| العمود | ما يُكتب | الشرط |
|---|---|---|
| **الرأي** | وصف موجز (≤40 كلمة) مع هويته | اسم صاحب الرأي أو المصدر |
| **السياق** (`context`) | متى سارِعاً صحيحاً | حالة السوق / المرحلة / الحجم |
| **الهدف** (`target`) | لمن هذه الاستراتيجية | شريحة عميل / قطاع |
| **الآلية** (`mechanism`) | كيف تعمل | السبب السببي |
| **الشروط** (`conditions`) | متى تنجح | ≥3 شروط قابلة للاختبار |
| **الشروط المضادة** (`counterconditions`) | متى تنقلب إلى فشل | ≥2 شرط |
| **القابلية للنقل** (`transferability`) | هل تنقل إلى سياق آخر؟ | نعم/لا + السبب |
| **الحالة** | مشروط / تجريبي / فرضية / متعارض / مستبعد / هبد | واحد فقط |

## حالات التقييم (الحقل `الحالة`)

- `مشروط`: الرأي صحيح ضمن شروط محددة — **الأكثر شيوعاً** في PLAYBOOK جيد.
- `تجريبي`: رأي يدعمه دليل قصير أو شهادة عملية غير قابلة للتعميم.
- `فرضية`: استنتاج الكاتب (`⚠️`) لم يجربه أحد.
- `متعارض`: توتر حقيقي بين رأيين معقولين ⇒ يستدعي `X_` تمييز.
- `مستبعد`: الرأي متناقض مع ≥3 أدلة ⇒ لا يُدرج في التوصيات.
- `هبد`: مبالغة بلا آلية قابلة للتتبع ⇒ يسقط.

## التعليمات الدقيقة للتعبئة

1. **ابدأ بسؤال الماستر واحداً** — بلا سؤال لا موقف.
2. **لا مصفوفة إلا مع توتر حقيقي**: إذا كان رأي واحد فقط سائداً ⇒ اكتب في `INDEX.md`: «لا ينطبق — لا تعارض آراء موثق في مصادر Outreach».
3. **كل سطر بلا `counterconditions` ⇒ يسقط** (العقد).
4. **حقل `الحالة` إلزامي لكل سطر** — رأي بلا حالة = هبد تلقائي.
5. **القابلية للنقل** تُحدد إن كان الرأي ينطبق على Outreach عامة أم على فرع محدد.
6. **التحقق قبل الاعتماد:**
   ```bash
   grep -c 'الحالة' "$f"  # ⇒ يجب أن = عدد الصفوف
   grep -c 'counterconditions' "$f"  # ⇒ يجب أن = عدد الصفوف
   ```
