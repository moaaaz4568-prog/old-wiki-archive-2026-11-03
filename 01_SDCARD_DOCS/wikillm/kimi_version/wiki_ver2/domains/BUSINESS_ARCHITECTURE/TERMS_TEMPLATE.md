## الحقول الإجبارية

| الحقل | الشرط | الخطأ القاتل |
|---|---|---|
| `term` (`C_Slug`) | `C_` + اسم بالعربي | `C_` ناقص أو اسم بالإنجليزية |
| `definition` | تعريف تشغيلي لا قاموسي | تعريف قاموسي = يسقط |
| `aka` | مصفوفة فارغة `[]` إن لم يوجد مرادف | حذف الحقل |
| `source` | `/sdcard/Nexus_Brain/...:line` | `source: <placeholder>` ⇒ يسقط |
| `depth` | الأساس · التعميق · حدّ الفناء | 1 سطر فقط ⇒ تسقط |

## التعليمات الدقيقة للتعبئة

1. **ابدأ بسؤال الماستر واحداً** — بلا سؤال لا مصطلح (ONTOLOGY.md).
2. **كل مصطلح يُعثر عليه من مصدر حقيقي** (find في `/sdcard/Nexus_Brain/Nexus_Brain/brain/`)؛
   إذا لم يوجد ⇒ لا تكتبه بل سجّل في `INDEX.md`: «لا ينطبق — لم يُعثَر على مصطلح <X> في المصادر».
3. **الحدّ الفناء ≥40 كلمة** (العقد: `≥40 كلمة`) — أقل من 40 كلمة ⇒ يسقط.
4. **aka** = مرادفات + أسماء بديلة؛ **لا تكتبها إلا إن وجدت فعلاً في المصادر**.
5. **التعميق** = 3-6 أسطر فقط (لا تحويل C_ إلى M_).
6. **التحقق قبل الاعتماد:**
   ```bash
   grep -c '^# ' "$f"                 # عدد المفاهيم = عدد ملفات C_
   grep -c '^---' "$f" | awk '{print $1/2}'  # عدد الملفات = عدد blocks YAML
   ```
