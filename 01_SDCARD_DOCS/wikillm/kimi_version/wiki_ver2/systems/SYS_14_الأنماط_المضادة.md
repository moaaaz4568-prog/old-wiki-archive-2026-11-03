## 2. أخطر 10 سيناريوهات (من 60 سيناريو)

### الفئة 1: التوسع (T1-T10)

**T1 — انفجار حجم الماستر الواحد:** عند 10K ملف تتحول الماسترات لملفات عملاقة غير قابلة للقراءة؛ عند 100K becomes أكبر من السياق.
- **الاكتشاف المبكر:** `wc -l masters/*.md \| awk '$1>4000'` يومياً.
- **الحماية:** قاعدة التقسيم المعلنة (GPT6 #51: «المبيعات موضوع ضخم بالتالي هنقسمه لكذا ماستر»).

**T2 — تدهور الفهارس عن الحقيقة:** الفهارس تبنّى وقت الإنشاء ولا تُحدّث.
- **الاكتشاف المبكر:** `find . -newer INDEX.md -type f \| wc -l` — أي عدد >0 = فهرس stale.
- **الحماية:** عقد الفهارس (`SYS_10`) + `index_check.py` بعد كل دفعة.

**T3 — انفجار البحث الدلالي:** 50 نتيجة لنفس المفهوم بأسماء مختلفة.
- **الاكتشاف المبكر:** `python3 tools/dedup_probe.py --sample 100` أسبوعيا.
- **الحماية:** Entity Resolution إلزامي + `aka:` لا ملف (`SYS_02`).

**T4 — امتلاء القرص:** دفعات 10K/100K تُسخّن قبل المعالجة.
- **الاكتشاف المبكر:** `df -h /sdcard` قبل كل دفعة + إنذار 20% حرة.
- **الحماية:** لا نسخة كاملة + checkpoint بالبصمات (`SYS_05`).

**T5 — مجلدات فوق حد GitHub (1000 ملف):** GitHub يحذفها صامتا.
- **الاكتشاف المبكر:** `find . -type d -exec sh -c 'ls "$1" | wc -l' _ {} \| awk '$1>900'`.
- **الحماية:** قاعدة R21 ≤900 + شطر تلقائي `part_NN` (`SYS_03`).

**T6 — تضارب الأرقام مع التوسع:** كل موجة تعيد العدّ بمنهج مختلف.
- **الاكتشاف المبكر:** `count.py --check` بعد كل موجة.
- **الحماية:** قاعدة sima_yi (`SYS_12`) + `counts-ref` أعلى كل وثيقة.

**T7 — شريحة ووكيل أكبر من السياق:** وكلاء يموتون بـcontext deadline.
- **الاكتشاف المبكر:** مراقبة token usage — أي وكيل >150k = إنذار.
- **الحماية:** حد ثابت 20-25 وحدة/وكيل (`SYS_13`).

**T8 — الاعتماد على CHECKPOINT بدل المانيفست:** النسب تُحسب من سجل قديم (38.6% حقيقي لا 61.5%).
- **الاكتشاف المبكر:** `wc -l manifest.jsonl` مقابل عدّ الملفات الفعلي.
- **الحماية:** قاعدة R09 صارمة + `coverage_check.py` قبل كل تخطيط موجة.

**T9 — انهيار ROUTER عند تعدد المجالات:** الوكيل يقرأ الماستر الخطأ.
- **الاكتشاف المبكر:** اختبار استرجاع دوري — 20 سؤالا معياريا.
- **الحماية:** ROUTER هرمي (`SYS_10`).

**T10 — ماسترز فرعية بلا حاكم عند 100K:** 500 ماستر متساوٍ بلا طبقة تجميع.
- **الاكتشاف المبكر:** كل ماستر فرعي يجب أن يظهر في فهرس ماستر أم واحد.
- **الحماية:** معمارية ثلاثية (Master Index → Parent → Sub) (`SYS_15`).

### الفئة 2: الوكلاء (A1-A10)

**A1 — موت الوكيل في منتصف مهمة:** 90% من الشغل ضاع.
- **الحماية:** append فوري + FIX فوري (`SYS_13`).

**A2 — النجاح الكاذب (81 شكوى):** «انتهيت» بلا ملفات.
- **الحماية:** قاعدة R09 — كل تقرير إنجاز يلزمه أمر shell شُغِّل + mخرجه مكتوب (`SYS_01`).

**A3 — الكتابة خارج النطاق:** تلوث متبادل بين المجالات.
- **الحماية:** `allowed_read/write_paths` + جدول صلاحيات (`SYS_01`).

**A4 — هلوسة المصادر:** 25 معرف SRC وهمي.
- **الحماية:** كل SRC يشير لملف موجود (`SYS_11`).

**A5 — التكرار بلا تقدم:** 3 فشلات متطابقة = إيقاف إجباري.
- **الحماية:** قاعدة NB2: عند فشل متكرر (≥2) قسّم فورا (`SYS_13`).

**A6 — العمل بنفسه بدل التفويض (R04):** 39 تكرارا.
- **الحماية:** دستور كل جلسة: النموذج = مخطط ومراجع فقط (`SYS_13`).

**A7 — شريحة أكبر من السياق:** مهمة واحدة ضخمة = موت شبه مؤكد.
- **الحماية:** تقسيم إجباري + حد 20-25/وكيل (`SYS_13`).

**A8 — تقرير منقطع يُعتبر نتيجة:** ازدواجية كتابة.
- **الحماية:** «التحقق من القرص هو الحكم» — idempotency (`SYS_13`).

**A9 — تجاوز البوابات بادعاء «استثناء»:** البوابات تتحول نصوصا.
- **الحماية:** البوابات حارسة لا حاجزة + مراجع مستقل (بوابة QA).

**A10 — تلوث صيني/لغوي:** نموذج يخلط صيني/عربي.
- **الحماية:** فاحص لغوي في `audit.py` + قائمة نماذج محظورة.

### الفئة 3: المحتوى (C1-C10)

**C1 — تلوث صيني (16 ماستر):** نص صيني يتسرب.
- **الحماية:** فاحص آلي في `audit.py` قبل اعتماد أي ملف.

**C2 — تحويل مثال لقاعدة (الخطأ التأسيسي):** نموذج ضعيف يجعل التكتيك قاعدة مطلقة.
- **الحماية:** الإدراك الرباعي + حدّ الفناء (`SYS_04`) + اختبار الوصفة الميتة.

**C3 — تناقض آراء يُحل بالحذف أو الدمج القسري:** تضيع المعرفة الشرطية.
- **الحماية:** مصفوفة السياق (`SYS_08`) + قاعدة التناقض.

**C4 — مصادر مكررة تُحسب مرتين:** الأرقام تتضخم.
- **الحماية:** هوية byte-exact (`SYS_05`).

**C5 — مصادر تالفة تُعالج كمحتوى:** مصطلحات وهمية من لا شيء.
- **الحماية:** سجل الشواذ بلا حذف (`SYS_05`).

**C6 — تعارض أرقام داخل وثيقة واحدة:** D04 يقول 6 والمرجع يقول 7.
- **الحماية:** NULL على الملف المتعارض (`SYS_12`).

**C7 — نسب على مقام خاطئ:** 99.99% محسوبة على ملفات لا مفاهيم.
- **الحماية:** قاعدة sima_yi — كل نسبة تحدد مقامها.

**C8 — تكرار قسم صامت:** ماستر بـ36 قسما (53.5% مكرر).
- **الحماية:** R20 فاحص آلي (`SYS_07`).

**C9 — أرقام بلا مصدر تتضخم بالتكرار:** 80%، 35%، 90% بلا أصل.
- **الحماية:** المسار العكسي Master→Concept→Claim→source_id.

**C10 — حشو كمي يقتل الجودة:** §15 يُملى حشوا.
- **الحماية:** العقد وظيفي لا كمي (`SYS_09`).
