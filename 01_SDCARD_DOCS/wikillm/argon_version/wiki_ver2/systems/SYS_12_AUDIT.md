# SYS_12 — التدقيق: بوابات قياس حرفية وتصنيف CASTRO

> النظام الحاكم للتدقيق: كل بوابة تقاس بأمر shell حرفي، كل بوابة لها جرس CASTRO يحدد أثرها، وكل رقم يخضع لقاعدة sima_yi. البوابات حارسة لا حاجزة — درس V3: بنية مثالية بصفر ماستر.

## §1 المبدأ الحاكم: البوابات حارسة لا حاجزة

درس V3 الموثق: نظام بُني ببوابات صارمة فأنتج **بنية مثالية بصفر ماستر** — البيروقراطية قتلت الإنتاج. لذلك:

- البوابة **تقيس وتسجل وتحذر** — لا تمنع الإنتاج الكلي.
- العتبات **وظيفية لا كمية**: يجوز «لا ينطبق» بالسبب الموثق.
- مقياس النجاح = مخرجات على القرص، لا اكتمال اللوائح (سيناريو 2.10 من المحاكاة).
- الاستثناء الوحيد الممنوع: تجاوز البوابة بادعاء «حالة خاصة» لغوياً (سيناريو A9).

## §2 تصنيف CASTRO — ثلاثة أجراس

| الجرس | التعريف | الأثر |

| **حاجب** | خلل في الهوية أو صحة المحتوى | يُرفض الكيان؛ لا فهرسة ولا إحصاء |

المصدر: GATES_11.md §1. كل بوابة في هذا النظام تحمل جرساً من الثلاثة، والتصنيف يحدد الأثر فوراً بلا تأويل.

## §4 قاعدة sima_yi — الأرقام (من TRUTH_NUMBERS.md)

```
الرقم الذي لا يقابله أمر shell يُلغى.
```

- **المصدر الوحيد للأرقام: `COUNTS.json`** — يُولَّد بـ`python3 tools/count.py` من القرص، ولا يُكتب رقم يدوياً في أي وثيقة.
- **كل نسبة تحدد مقامها صراحة:** ملف ≠ مفهوم ≠ مصدر مستقل — الأرقام الثلاثة مختلفة جوهرياً (درس V3: 29,585 ملفاً لكن 1,836 مفهوماً فقط؛ نسبة «99.99%» حُسبت على الملفات لا المفاهيم فكانت باطلة).
- تعارض رقمي لا يُحسم بالتأويل ⇒ إعلان NULL على الملف المتعارض كله.
- `count.py --check` يوسم كل رقم مخالف بـ⚠️ ويُشغَّل بعد كل موجة كتابة.

## §5 فاحص التلوث CJK

التلوث الصيني حدث فعلاً: 16 ماستر ملوثاً في الويكي القديمة. الفاحص الإلزامي بـPython (لا `grep -P` مع `\x{}` — تفشل على هذا الجهاز):

```bash
python3 -c "import pathlib; print(sum(1 for p in pathlib.Path('/sdcard/wikillm/argon_version/wiki_ver2').rglob('*.md') for c in p.read_text(errors='ignore') if '\u4e00' <= c <= '\u9fff'))"   # ⇒ 0
```

أي حرف صيني في أي ملف = جرس حاجب: عزل فوري وإصلاح من المصدر الأصلي (لا إعادة كتابة من الذاكرة). الفاحص مدمج في `tools/audit.py` (بوابة G1 بوزن 25).

## §6 دورة التدقيق

1. **بعد كل ملف جديد:** فحص النقاء + الأقسام + وسوم التعليق (أوامر 1، 4، 5).
2. **بعد كل موجة كتابة:** `python3 tools/audit.py /sdcard/wikillm/argon_version/wiki_ver2/` كامل + `python3 tools/count.py --check`.
3. **قبل كل git push:** فحص سقف المجلدات (أمر 3) — GitHub يحذف المجلدات الكبيرة صامتاً.
4. **قبل اعتماد أي ماستر:** فحص SRC حقيقي (أمر 6) — 25 معرفاً وهمياً اكتُشفت بهذه الطريقة في NEXUS_OS.
