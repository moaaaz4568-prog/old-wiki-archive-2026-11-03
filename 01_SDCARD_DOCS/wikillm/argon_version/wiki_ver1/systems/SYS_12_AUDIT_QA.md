# SYS_12 — التدقيق وضمان الجودة (Audit & QA)

**المرجع:** NEXUS_OS_COMPREHENSIVE_SYSTEMS_BLUEPRINT.md §3.12

## §1 الفحوص الإلزامية (قبل اعتماد أي ملف أو دفعة)

### 1. فحص التلوث اللغوي
```bash
grep -rP '[\x{4e00}-\x{9fff}]' <المجلد>/
```
أي نتيجة = فشل فوري. السبب: 16 ماستر في الويكي القديمة ملوثة بالنصوص الصينية (10_FULL_CONTEXT.md §2).

### 2. فحص المصادر
- كل ادعاء رقمي له `path:line` قابل للتحقق.
- كل تكتيك في §6 موسوم بخبيره وسياقه.
- كل مصدر في SOURCES_CATALOG موجود فعلاً على القرص.

### 3. فحص الانزلاق للآيس بريك
- ابحث عن صيغ القانون المطلق: "دائماً"، "أبداً"، "يجب أن" في تكتيكات §6.
- كل تكتيك يجب أن يكون له "متى يفشل" — تكتيك بلا حدود فشل = مشبوه.

### 4. فحص سلامة الروابط
- كل إحالة داخلية لمسار موجود فعلاً.
- كل INDEX.md يطابق الملفات الموجودة فعلاً في مجلده.

### 5. فحص الهياكل الفارغة
- لا TODO ولا placeholders في ملفات معتمدة.
- أي قسم إطاري (بانتظار مصادر) موسوم صراحة في SOURCES_CATALOG: "بانتظار مصادر — الإطار الحالي من تحليل معماري".

## §2 دورية التدقيق

- **بعد كل دفعة مصادر:** فحوص 1-3 على الملفات المعدلة.
- **أسبوعياً (أو كل 5-10 مصادر):** فحص كامل + wiki-lint (يتامى، تناقضات، روابط مكسورة).
- **قبل أي تسليم للمالك:** الفحوص الخمسة كاملة + المراجعة الذاتية الرباعية (AGENTS.md §6).

## §3 أداة التدقيق

```bash
# فحص التلوث الصيني في النسخة كاملة
grep -rP '[\x{4e00}-\x{9fff}]' /sdcard/wikillm/argon_version/wiki_ver1/ && echo "ملوث" || echo "نظيف"

# فحص الروابط الداخلية المكسورة (مثال يدوي)
grep -rhoP '\]\((?!http)[^)]+\.md\)' systems/ domains/ | sort -u
```

## §4 التعامل مع النتائج

| النتيجة | الإجراء |
|---|---|
| تلوث صيني | إصلاح فوري — إعادة كتابة المقطع بالعربية الأصيلة |
| ادعاء بلا مصدر | إضافة "غير مذكور" أو حذف الادعاء الرقمي (ليس رأي الخبير) |
| تكتيك بلا حدود فشل | إضافة صف في CONTINGENCY_MATRIX |
| رابط مكسور | إصلاح المسار |
| قسم فارغ | تسجيله صراحة كإطاري أو ملؤه من مصادر |

## §5 قاعدة الصدق

فشل التدقيق يُعلن للمالك كما هو — التغليف ممنوع. "قولى عملت ايه بالضبط" (رسائل المالك المتكررة). التقرير يتضمن: ما أُنجز بأرقام، ما فشل ولماذا، ما المتبقي.
