# Nexus Wiki OS — النسخة المرجعية (argon / wiki_ver1)

**تاريخ البناء:** 2026-10-24 · **الباني:** نموذج argon (Gemini 4 Argon) · **المالك:** moaz (zeyusmoaz@gmail.com)

## ما هذا النظام؟

هذا ليس أرشيفاً ولا مكتبة نصوص. هذا **نظام تشغيل إدراكي (Cognitive Operating System)** يحوّل أي نموذج لغوي — مهما كان ضعيفاً — إلى مهندس أعمال ومغلق صفقات وخبير أوتريتش فور قراءته للويكي.

الفكرة الجوهرية: المعرفة الميدانية الحقيقية (من خبراء مثل غيث عماد، محمد أسامة، هورموزي، BeContent، Instantly.ai، Sabri Nagy وغيرهم) تُستوعب **دون فواقد**، وتُحلَّل عبر **الإدراك الرباعي**، وتُجمَّع في **بلاي بوك جامعة حية** جاهزة للعمل من المصدر الأول.

## كيف يعمل النظام؟

```
المصدر الخام (raw/) → صندوق الاستقبال (intake/) → تصنيف لمجال (domains/)
→ قراءة كاملة → استخراج المفاهيم → تحليل بالإدراك الرباعي
→ دمج فوري في PLAYBOOK.md + TERMS.md + SOURCES_CATALOG.md
→ أي نموذج يسترجع المقطع المطلوب فوراً (tools/nexus_rag.py)
```

لا بوابات تعليق. لا ملفات مجهرية. لا حذف آراء. الويكي تعمل من اليوم الأول وتزداد عمقاً مع كل مصدر.

## كيف يدخل نموذج جديد ويبدأ العمل فوراً؟

1. اقرأ `START_HERE.md` — نقطة الدخول الإلزامية.
2. اقرأ `AGENTS.md` — دستورك: أدوارك وقواعدك وبروتوكول تفكيرك.
3. اقرأ `systems/SYS_01_CORE_CHARTER.md` ثم `SYS_04_COGNITIVE_REASONING.md` — هذان النظامان يحددان كيف تفكر.
4. اذهب إلى مجال المهمة في `domains/` واقرأ `INDEX.md` الخاص به ثم الـ PLAYBOOK.
5. نفّذ. عند أي حيرة، استخدم `tools/nexus_rag.py` لاسترجاع المقطع المناسب.

## المبادئ الدستورية الخمسة (المصدر: NEXUS_OS_PERFECT_ARCHITECTURE_SPEC.md)

1. **Zero Data Loss** — كل مصدر يدخل بكامل تفاصيله؛ لا يحق لأي نموذج الحكم على كلام الخبراء.
2. **Pluralism & Contingency Matrix** — الرأيان المتعارضان يُوثقان معاً: متى ينجح كلٌّ ومتى يفشل.
3. **الإدراك الرباعي** — (حقيقة نفسية ← مبدأ استراتيجي ← تكتيكات موسومة ← مصفوفة أمان).
4. **Consolidated Living Playbooks** — ملف جامع حي لكل قسم، بلا ملفات مجهرية.
5. **جاهزية مليونية** — خفيفة، مفهرسة، تتحمل 100K+ ملف.

## حالة هذه النسخة (محدّثة 2026-10-25 بعد إغلاق النواقص)

**ما هو موجود فعلاً الآن (بأوامر قياس حقيقية):**
- `systems/`: 15 نظاماً كاملاً (SYS_01 → SYS_15) — قياس: `find systems -name "SYS_*.md" | wc -l` ⇒ 15.
- `domains/`: 5 مجالات + 8 أقسام فرعية + 14 فهرس INDEX.md (جذر + 5 مجالات + 8 أقسام). كل قسم فرعي يحوي 4 ملفات: `PLAYBOOK.md` (قالب §1-§10 بتعليمات دقيقة + مثال توضيحي موثق بمصدر حقيقي)، `TERMS.md`، `SOURCES_CATALOG.md`، `CONTINGENCY_MATRIX.md`.
- `raw/SOURCE_MANIFEST.tsv`: مانيفست المصادر الخام وسياسة الحماية — يشير لمستودع `/sdcard/Nexus_Brain/Nexus_Brain/brain/` (5,126 ملفاً — قياس حقيقي: `find ... -type f | wc -l` ⇒ 5126).
- `intake/README.md`: دورة حياة الملف الجديد بمراحلها الخمس.
- `tools/nexus_rag.py`: أداة استرجاع فعلية (stdlib فقط) — مختبرة: `python3 tools/nexus_rag.py --selftest` ⇒ PASS، وبحث تجريبي عن "cold email" في مستودع المصادر أعاد 3 نتائج مرتبة بالدرجة.
- `_BUILD_REPORT.md`: تقرير البناء بأرقام مُشغّلة فعلاً.

**المرحلة الحالية:** بناء الأنظمة والهيكل والقوالب فقط — الـ PLAYBOOKs قوالب جاهزة للتعبئة، وملؤها مرحلة تنفيذية لاحقة عبر موجات وكلاء (20-25 مفهوماً/وكيل) بعد اكتمال استخراج مصطلحات كل مجال من المصادر الخام.

هذه نسخة ver1 مبنية للمقارنة مع نسخ نماذج أخرى (glm, haiku, kimi). راجع `_BUILD_REPORT.md` للأرقام الحقيقية وما أُنجز وما عُجز عنه. المرحلة التالية: مراجعة متبادلة → wiki_ver2 → نقاش جماعي → final_wiki.
