# SYS_10 — الفهارس والاسترجاع (Indexing & Retrieval)

**المرجع:** NEXUS_OS_COMPREHENSIVE_SYSTEMS_BLUEPRINT.md §3.10 · NEXUS_OS_PERFECT_ARCHITECTURE_SPEC.md §5.5

## §1 طبقات الفهرسة

1. **فهرس الجذر:** `README.md` — خريطة النظام الكاملة.
2. **فهرس المجالات:** `domains/INDEX.md` — أي مجال لأي هدف؟
3. **فهرس كل مجال وقسم:** `INDEX.md` — وظيفة كل ملف.
4. **فهرس داخل الملف:** كل PLAYBOOK يبدأ بفهرس أقسامه §1-§10.
5. **فهرس المصادر:** `SOURCES_CATALOG.md` في كل قسم.

## §2 قاعدة الفهرس الإلزامية

كل مجلد بلا INDEX.md = عيب معماري يجب إصلاحه فوراً. الفهرس يخبر أي وكيل مستقبلي: وظيفة المجلد، وظيفة كل ملف، وأين يذهب لهدف معين. (المصدر: رسالة المالك #51: "فهرس يقول للايجنت كل ملف عبارة عن ايه ووظيفته ايه")

## §3 محرك الاسترجاع (tools/nexus_rag.py)

أداة Python خفيفة (grep ذكي) لاسترجاع المقاطع بأقل توكنز:

```bash
# بحث بالمصطلح عبر كل الويكي
python3 tools/nexus_rag.py "icebreaker"

# بحث داخل مجال محدد
python3 tools/nexus_rag.py "اعتراض السعر" --domain sales

# بحث داخل قسم محدد
python3 tools/nexus_rag.py "deliverability" --section outreach/01_cold_email_systems

# عرض قاموس مصطلحات قسم
python3 tools/nexus_rag.py --terms sales/02_objection_handling
```

المخرج: اسم الملف + رقم السطر + المقطع المحيط — يقفز النموذج للمقطع مباشرة دون قراءة ملفات كاملة.

## §5 قاعدة السياق

- الاسترجاع النقطي للمقاطع عند الأسئلة المحددة.
- القراءة الكاملة للـ PLAYBOOK عند المهام المركبة — لا تعتمد على RAG لمهمة تحتاج 40 مفهوماً متداخلاً (سبب فشل RAG المجزأ: MASTER_SYNTHESIS_AND_DEEPENING_BLUEPRINT_2026.md §1).
