## دروس إلزامية لأي وكيل مستقبلي (نموذج Gemini 4 Argon Free [Direct] Yukino via 9Router)
1. **أداة `task` بـsubagent_type=general تعمل** — موثقة في وثائق opencode.ai (سطر 1247): `general-purpose agent ... full tool access ... run multiple units of work in parallel`. هذه هي القناة الأولى.
2. **delegate_task معطلة نهائياً** — ترجع `[ERROR] [object Object]` لكل الأنواع (zen-worker، zen-researcher، general). لا تحاول مرتين.
3. **`opencode run` بطيء/معلق** — يعلق في bootstrap حتى بلا subagent (timeout 160s بلا مخرج). لا تستخدمه كقناة وكلاء.
4. **Antigravity (agy) ممنوعة نهائياً** — المستخدم منعها صراحة (سطر 430). أي استخدام = إيقاف قسري وخسارة ثقة.
5. **القناة الاحتياطية المؤكدة: 9Router API مباشرة** — `POST http://127.0.0.1:20128/v1/chat/completions` بنموذج `gemini-4-argon-free` يعمل (استجابة موثقة سطر 1452). لكن **انتبه**: الاستجابة قد تأتي SSE (`data: ...}data: [DONE]`) — فك التغليف قبل json.loads، أو استخدم `"stream": false` صراحة.
6. **لا تكرر أمر المستخدم 15 مرة بلا استجابة** — أول تكرار = بحث فوري + اختبار عملي + توثيق النتيجة في ملف.
7. **حدّث تقرير البناء بعد كل موجة** — التقرير الراكد كشفه المراجع وأحرج النموذج.
8. **تحقق من أسماء الملفات المرجعية بـtest -e** قبل كتابة أي فهرس (خطأ START_HERE.md أسطر 59-68).
9. **اكتب سكريبت subagent مع معالجة SSE من اليوم الأول** — النمط: اقرأ السطر، احذف بادئة `data: `، تجاهل `[DONE]`، جمّع deltas.
10. **عند فشل صامت: اقرأ الـlog الخام** — log1.txt كشف سبب الفشل فوراً؛ النموذج لم يقرأه.
