## القسم 1 — فهرس الأخطاء الكامل (بالأدلة)

### الخطأ 1: إيجابيات كاذبة في فحص الحروف الصينية بأمر grep (سطور 16–106)

أمر فحص CJK في البروتوكول (القسم 6) أنتج **73 مطابقة كاذبة** في `systems/SYS_06_TERMS_DEEPENING.md`، منها السطر 1 نفسه وهو عنوان عربي خالص:

```
# SYS_06 — نظام استخراج المصطلحات والتعميق الإدراكي (Terms Deepening System)
```

**السبب الجذري:** البيئة تعمل بـlocale من نوع POSIX (السطور 61–75: `LC_ALL` فارغ و`LC_CTYPE=POSIX`)، فيفسر grep نمط `[U+4E00-U+9FFF]` على مستوى البايتات لا المحارف، فيطابق أي بايت عربي مرتفع.

**سلوك الأمر تحت الإعدادات المختلفة:**

| الإعداد | النتيجة | دليل السجل |
|---|---|---|
| `grep` الافتراضي | 73 مطابقة (كلها كاذبة) | السطر 42 |
| `LC_ALL=C grep -c` | 73 مطابقة (كلها كاذبة) | السطر 77 |
| `LC_ALL=C.UTF-8 grep -c` | خطأ: `Invalid collation character` | السطر 79 |
| Python (المحارف Unicode) | **CJK total: 0** — صفر حروف صينية فعلياً | السطور 92–98 |

**الحكم:** النموذج أهدر نحو 10 أدوار تشغيل قبل أن يشخّص المشكلة صحيحاً بنفسه (السطر 106: «grep الافتراضي في POSIX locale يطابق العربية... البديل المضمون هو Python»). الخلل الأساسي في أمر البروتوكول نفسه، لكن النموذج نفّذه أولاً دون توقع سلوك الـlocale.

### الخطأ 2: بنية الوكلاء الفرعيين delegate_task معطلة بصمت (سطور 110–126، 184–196، 548–652، 1113)

- أُطلقت ستة مهام عبر `delegate_task` (منها `task_1c365085`، `task_598771d5`، `task_8cd0c0bd`، `task_86af3523`، `task_bb4bb238`، `task_285d70ca`).
- استرجاع النتائج عبر `get_task_result` فشل بصمت برسالة `[ERROR] [object Object]` (السطور 195، 633).
- `check_background` أرجع: `Task not found. No background tasks exist` (السطر 651).
- النتيجة النهائية المؤكدة في السطر 1113: الأداة معطلة لكل أنواع الوكلاء في هذه البيئة.

**الحكم:** فشل صامت مضلل — المهام «تنطلق» ظاهرياً ثم تختفي بلا أثر ولا رسالة خطأ مفهومة.

### الخطأ 3: تشغيل AGY (Antigravity) رغماً عن نهي المستخدم (سطور 395–529)

### الخطأ 4: علق أوامر opencode run وتكرار المحاولة نفسها (23 ذكراً في السجل؛ 9 انتهاءات بمهلة زمنية)

```
python3 - <<'EOF'
import pathlib
bad = []
for p in pathlib.Path('.').rglob('*.md'):
    t = p.read_text(errors='ignore')
    n = sum(1 for c in t if '\u4e00' <= c <= '\u9fff')
    if n:
        bad.append(f"{p}: {n}")
print('CJK CLEAN' if not bad else 'CJK FOUND:\n' + '\n'.join(bad))
EOF
```
