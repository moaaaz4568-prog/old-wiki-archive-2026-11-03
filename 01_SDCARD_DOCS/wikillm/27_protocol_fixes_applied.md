## الإصلاح 3 — استبدال فحص grep بفاحص Python في القسم 6
- **الموقع:** القسم 6، كتلة الأوامر الحرفية (كان السطر 193 قبل التعديل).
- **قبل:**
  ```bash
  grep -rn "$(python3 -c "print('['+chr(0x4e00)+'-'+chr(0x9fff)+']')")" <مجلدك>/ | wc -l   # صفر = نقاء لغوي
  ```
- **بعد:** فاحص heredoc بـPython حصراً (يعمل من داخل `<مجلدك>`، يطبع `CJK CLEAN: 0` أو `CJK FOUND: N`) + بديل بسطر واحد + تعليق تحذيري يشرح السبب: **grep في POSIX locale يطابق بايتات العربية كأنها CJK وينتج إيجابيات كاذبة (73 نتيجة خاطئة موثقة في مراجعة ses_e8df)**.
- **السبب الجذري (من المراجعة):** POSIX locale يجعل grep يقرأ الملفات بايت-بايت فتتطابق بايتات UTF-8 العربية مع نطاق CJK.
