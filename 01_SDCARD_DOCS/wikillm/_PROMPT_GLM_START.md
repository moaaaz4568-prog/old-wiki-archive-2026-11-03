**أول أمر إلزامي قبل كتابة أي سطر:** اقرأ `/sdcard/wikillm/BUILD_PROTOCOL.md` كاملاً — هذا دستورك الحاكم، وكل ما يلي مجرد تذكيرات لا بديل عنه. البروتوكول يفرض عليك قراءة ملفات إلزامية قبل أي عمل (القسم 1: السياق الكامل، رؤية المالك، نواياه الحرفية، تحليل الويكيات الخمس، سيناريوهات المحاكاة، وثائق V3 في `/root/r/V3/00_CHARTER/`). اقرأها كلها بالترتيب ثم اكتب في أول رد: تفسيرك للمهمة + خطتك + ما قد يفشل + معايير قبولك (القسم 5).

**قناة sub agents — الحظر الرباعي الصارم:**
1. **القناة الوحيدة المسموحة:** أداة `task` بـ`subagent_type=general` (أو worker/reviewer) — تجري بنفس نموذجك وتعمل فعلاً.
2. **ممنوع نهائياً — لا محاولة ولا استثناء:**
   - **Antigravity / agy-director.mjs** — محظورة حرفياً من المالك؛ أي استخدام = إيقاف قسري وفقدان ثقة كامل.

   - **9Router API المباشر** — يرجع SSE (`}data: [DONE]`) ويفشل JSONDecodeError إلا مع معالج SSE مكتوب من اليوم الأول؛ لا تلجأ إليه إلا كخيار أخير بعد إعلان فشل `task`.
