# SYS_05 — الاستيعاب (إدخال المصدر/Source Ingestion)

> النظام الحاكم لدخول أي معرفة جديدة إلى wiki_ver2. القاعدة صفر:
> **Zero Data Loss** — لا حذف، لا فلترة، لا ادعاء بأن التسجيل يساوي الفهم.

## الغرض

حوّل كل ملف مصدر إلى هوية قابلة للتتبع (بصمة SHA-256) دون تعديل الخام،
دون حذف النسخ المتطابقة، ودون بوابة ادعاءات (Claims) تعطل الاستيعاب.
كل المصدر يدخل بكامل محتواه — الآراء المختلفة تُحفظ بمصفوفة سياقها، لا
تُفلتر.

## ما نتجنبه

- **نظام Claims:** المالك حظره حرفياً. تجربة GPT-6 فهرست 2,541 ملفاً
  فعالجت 3 فقط بسبب بيروقراطية الادعاءات — هذا الفشل لا يتكرر. كل رأي
  يدخل بمصفوفة سياقه (من قال/أين/بأي scope) بلا بوابة فلترة.
- **حذف النسخ المتطابقة:** التطابق بالبصمة لا يعني الحذف — canonical
  واحد والبدائل تُسجَّل كروابط.
- **الخلط بين الحالات:** registered/route_done/source_done/domain_done
  حالات منفصلة؛ `processed` لا تُرفع إلى `complete` تلقائياً.
- **hash بلا قراءة دلالية:** البصمة هوية، ليست فهماً.

## القواعد التنفيذية

1. **الهوية قبل كل شيء:** احسب بصمة SHA-256 لكل البايتات الأصلية قبل أي
   تطبيع. قارن الحجم والبصمة قبل/بعد — الملف المتغير يُوقف.
2. **route_done جائزة قبل extraction** بعد قراءة دلالية كاملة (full
   semantic read) + نسخة مستقلة byte-exact متحققة في
   `done/<domain>/<subdomain>/` (لا symlink/hardlink). source_refs فهارس
   ثانوية فقط.
3. **الفرز لأي مجال جائز؛ المعرفة في المجال النشط فقط** والباقي `queued`.
   لا عزل (quarantine) إلا لفساد أو تعذر قراءة — غموض الصلة حالة
   `uncertain` لا عزل سلامة.
4. **source_done** = استخراج كامل المصطلحات (terms) مع QA — بلا اشتراط
   Concepts أو Master. أثناء القراءة الاستخراجية سجّل المصطلحات والآراء
   المرشحة معاً بمواضعها دون انتظار اكتمال المجال.
5. **delta تجعل التغطية stale:** وصول ملفات جديدة إلى مجال مكتمل يجدول
   مراجعة في queue. فقط domain_done يجيز فتح المجال التالي — لا فتح
   مجالين معاً.
6. **idempotent:** إعادة التشغيل لا تنشئ سجلاً ثانياً لنفس البصمة. قسّم
   الإدخال إلى دفعات ثابتة واحفظ checkpoint بعد كل دفعة مربوطاً بالبصمات.
7. **لا نقل أو حذف للخام (raw):** يُقرأ في مكانه. المسارات المسجلة نسبية
   إلى جذر الويكي وقابلة للحل بلا traversal.
8. **التطابق بالبصمة لا بالاسم:** نفس الاسم ببصمتين ليس تكراراً؛ التشابه
   النصي وحده `uncertain` لا دليل.

## مثال تطبيقي

نفس بصمة SHA-256 بمسارين: canonical واحد + سجل duplicate واحد. لا حذف
ولا تضخيم أدلة — المساران محفوظان والنسخة الثانية ليست دليلاً مستقلاً.
ملف سليم القراءة في `queued`: route_done والنسخة مسموحان، والاستخراج
ينتظر دوره.
