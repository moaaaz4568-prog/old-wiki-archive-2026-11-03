# wiki_ver2 — نظام التشغيل الإدراكي للويكي (Cognitive Wiki OS)

> **wiki_ver2 ليس ويكي أخرى.** هو نظام تشغيل (Operating System) للمعرفة التجارية:
> خمسة أنظمة حاكمة (SYS_01..SYS_05) تحوّل أي نموذج لغة إلى مهندس أعمال استراتيجي
> ومغلق صفقات محترف، بمعرفة موثقة المصدر، مقيسة الأرقام، محدودة الفشل.

## ما هذا المشروع؟

مستودع معرفة للأعمال والذكاء الاصطناعي — كل رقم دقيق ومُقاس، كل concept بآلية
وحدود فناء، كل master مبني من مفاهيمه لا من قالب، ممنوع القواعد بلا سبب سببي
(أصل الرؤية: `/sdcard/nexus_wiki/00_PROJECT/goals.md:1327`).

> مؤرشفة في `_archive/` وجذورها tombstones — المرجع الحي هو `systems/` حصراً.

## نقطة الدخول

ابدأ من `START_HERE.md` — خريطة القراءة الإلزامية بترتيبها.

## ما يميز wiki_ver2 عن كل ما سبق

1. **صفر فقدان بيانات** (Zero Data Loss Ingestion) — المصدر يدخل بكامل محتواه.
2. **تعددية رؤى** (Pluralism & Contingency Matrix) — لا إجابة واحدة؛ مصفوفة بدائل مشروطة.
3. **إدراك رباعي** (Fourfold Cognition) — فك الارتباط بين المبدأ والتكتيك الموسوم بسياقه.
4. **ماسترز حية** (Consolidated Living Playbooks) — 18 قسماً مبنيّة من مفاهيم القطاع.
5. **جاهزية مليونية** — بنية تستوعب مليون ذرّة ومحركات استرجاع من طراز Muse.ai.

## الأوامر الأساسية

```bash
# فحص صحة الأنظمة الخمسة (معايير القبول الحرفية — من داخل wiki_ver2/)
grep -c "R0" systems/SYS_01*.md          # ≥ 5
grep -c "aka:" systems/SYS_02*.md        # ≥ 1
grep -c "S_\|T_\|C_\|X_\|G_\|P_\|M_\|Y_" systems/SYS_03*.md   # ≥ 8
grep -c "حدّ الفناء\|حدود فشل" systems/SYS_04*.md  # ≥ 3
grep -c "SHA-256\|بصمة" systems/SYS_05*.md  # ≥ 3
find systems -name "SYS_*.md" | wc -l    # = 5
```

## حدود النظام

- النظام حي متوسع: كل نمط جديد يستحق نظاماً مستقلاً (`SYS_06`, `SYS_07`, ...).
- القرص `/sdcard` ممتلئ 97% (1.7G متاح) — كل كتابة كبيرة تسبقها فحوصات مساحة.
- ممنوع الحذف نهائياً: `rm` `rmdir` `shred` `dd` `trash` = **deny** في جدول الصلاحيات.
