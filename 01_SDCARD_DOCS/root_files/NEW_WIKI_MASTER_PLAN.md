## 🎨 كيفية الاستخراج (الطريقة الصحيحة)

### المبدأ الأساسي:
```
لا تأخذ المثال كقاعدة!
استخرج الجوهر → الآلية → الحدود
```

### مثال تطبيقي (Ice Break):

#### ❌ الطريقة الخاطئة (V1):
```
المصدر: "كرر اسم البراند 3-4 مرات"
الاستخراج: "خطوات Ice Break: كرر 3-4 مرات"
المشكلة: أخذ المثال كقاعدة!
```

#### ✅ الطريقة الصحيحة (V3):
```
المصدر: "كرر اسم البراند 3-4 مرات"

التحليل:
1. ما الهدف؟ → كسر النمط
2. لماذا التكرار يعمل؟ → غير متوقع
3. هل التكرار الطريقة الوحيدة؟ → لا!
4. ما الآلية العامة؟ → أي شيء يكسر النمط المتوقع

الاستخراج:
  الآلية: كسر النمط المتوقع في البريد
  الأمثلة:
    - التكرار (مثال من المصدر)
    - السؤال المفاجئ
    - البداية العكسية
    - ...
  الجوهر: المفاجأة والفضول
  حدود التطبيق:
    - لا يعمل مع جماهير رسمية جداً
    - يحتاج مصداقية في الجملة التالية
```

## 🏗️ خطة التنفيذ

### المرحلة 0: التحضير (يوم 1)
1. **إنشاء الهيكل الأساسي** في `/sdcard/wiki/`
2. **كتابة ملفات Systems:**
   - لماذا كل مجلد؟
   - كيف كل عملية؟
   - دروس الأخطاء (Ice Break)
3. **نقل المصادر** من V1 إلى `raw/done/`

### المرحلة 1: الاستخراج (أيام 2-4)
1. **قراءة المصادر** من `brain/`
2. **استخراج المفاهيم** بالطريقة الصحيحة:
   - فهم الجوهر
   - استخراج الآليات
   - تحديد الحدود
3. **كتابة في** `concepts/`

### المرحلة 2: التعميق (أيام 5-7)
1. **تعميق كل مفهوم:**
   - تحليل واستكشاف
   - محاكاة السيناريوهات
   - البدائل
2. **بناء الروابط** بين المفاهيم

### المرحلة 3: الماسترز (أيام 8-12)
1. **تصنيف المفاهيم** حسب المجالات
2. **بناء Core Masters:**
   - Outreach Core
   - Sales Core
   - AI Core
   - ...
3. **بناء Specialized Masters:**
   - للمشاكل المحددة
   - داخل مجلد كل مجال

### المرحلة 4: الفحص (أيام 13-14)
1. **Quality Check:**
   - كل مفهوم فيه الجوهر؟
   - كل ماستر فيه §1-§18؟
   - كل رابط شغال؟
2. **Test with LLM:**
   - اسأل عن Ice Break
   - اسأل عن Outreach
   - شوف لو فهم الجوهر
