# مجلد الاحتياطي والطوارئ — `_RESERVE/`

## الغرض
هذا المجلد مخصص كحيز تنفس وهوامش أمان تشغيلية (Safety Buffer) ضمن ميزانية الأرشيف الـ 250MB.

## الشروط والقواعد
- لا يُستخدم إلا في حال وجود بيانات تكميلية حاسمة تظهر مستقبلاً.
- الحد الأقصى المسموح له: 24MB.
- الحالة الحالية: فارغ كاحتياطي استراتيجي نقي.
